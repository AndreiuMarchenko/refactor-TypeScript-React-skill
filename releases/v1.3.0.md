# v1.3.0 — React architecture and measured optimization

This release expands the skill's React-specific architecture guidance and adds a workflow for choosing and verifying performance improvements.

## Changes

- Four official React sources cover component boundaries and data flow, shared state ownership, custom Hooks, and render purity. Each entry identifies the relevant engineering decision and behavior to verify.
- Five performance sources cover React Profiler, `memo`, `useMemo`, React Compiler, and Chrome DevTools runtime analysis. Read them for a relevant scenario rather than introduce tooling or memoization by default.
- React-owned state and lifecycle favor function components and Hooks. Classes for non-React resources or domain invariants require a concrete ownership benefit.
- Performance work records a reproducible baseline, profiles the bottleneck, selects a focused change, repeats comparable measurements, and verifies observable behavior and tradeoffs.
- Reporting distinguishes measured historical baselines from profiler estimates, and verified cleanup from a demonstrated speedup. Existing compiler coverage is checked before adding manual memoization.
- Skill metadata and README now identify version `1.3.0`.
