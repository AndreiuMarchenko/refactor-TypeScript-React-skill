# v1.0.0 — Source-driven TypeScript/React refactoring

First release of the `source-driven-refactor` Agent Skill for Codex, Claude Code, and Cursor.

- Source-based architecture and contract review, resource ownership, lifecycle cleanup, and behavior verification.
- Explicit legacy cleanup: migrate callers, remove superseded execution paths and duplicate logic, and document compatibility adapters that must remain.
- README Before/After excerpts linked to a runnable React/TypeScript notifications application.
- Locked demo dependencies, shared component behavior checks, wire-decoder checks, expected-failure baseline verification, and a production module-graph guard.
- GitHub Actions validation for the demo on Node 24.

## Validation

Validated by manually applying the skill workflow to the executable demo included in this repository. Before exhibits six expected component regressions while six preserved behavior checks pass. After passes all 12 component checks and six decoder checks. Type-checking, production build, cleanup review, and skill metadata validation pass. See [the validation record](https://github.com/AndreiuMarchenko/refactor-TypeScript-React-skill/blob/v1.0.0/examples/react-demo/README.md#validation-record) for commands, evidence, and limitations.

This is a reproducible reference application created for the skill; no external production-project validation or independent agent benchmark is claimed.

## Install

Download the tag's source archive and follow the [installation instructions](https://github.com/AndreiuMarchenko/refactor-TypeScript-React-skill/blob/v1.0.0/README.md#installation). The skill identifier and installation folder are `source-driven-refactor`. Only `SKILL.md`, `LICENSE`, `agents`, and `references` are required for the installed skill; the demo is optional.
