# v1.1.0 — Behavioral review and migration evidence

This release packages the expanded review and migration-reporting workflow for the `source-driven-refactor` Agent Skill.

## Changes

- Behavioral review checks distinguish missing fields, `undefined`, and `null`; verify metadata precedence through the decoder-to-consumer path; distinguish captured inputs from live state; and protect newer explicit user intent during deferred reconciliation.
- Subscription checks cover prepopulated state, updates around setup, initial reconciliation, stop/start, replacement, and ownership-safe cleanup.
- Error review identifies expected failures, preserves unexpected causes through diagnostics or contract-defined propagation, and verifies partial setup/cleanup. Assertions must establish consumer-visible final state across boundaries rather than rely only on call counts.
- A structural completion gate requires reviewing responsibility boundaries at their final locations, including relocated implementations and adapters.
- Folder migration reports and a shared completion record capture implemented decisions, measured cleanup, remaining dependencies, current verification, and finite closure criteria. Templates are included under `assets`.
- Installation examples now copy `assets` with the skill's other runtime resources; Codex's default prompt includes migration evidence for implementation work.
- Skill metadata now records version `1.1.0`.

## Validation

The skill metadata, packaged resources, local documentation links, and installation layout were checked. The existing React demo passes all 18 After checks; baseline verification reproduces the six expected Before regressions while preserving six behavior checks. Type-checking and the production build pass.

The demo provides regression coverage for its notifications scenario. It does not exercise every newly documented behavioral invariant or establish an independent agent evaluation of the expanded reporting workflow.

## Install or update

Follow the [installation instructions](https://github.com/AndreiuMarchenko/refactor-TypeScript-React-skill/blob/v1.1.0/README.md#installation). Include `SKILL.md`, `LICENSE`, `agents`, `references`, and `assets`. When updating an existing installation, refresh these resources together so the new references and report templates are available.
